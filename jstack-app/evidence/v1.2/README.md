# evidence/v1.2

Artefacts from the **v1.2** build, kept for provenance and cited by no V2 or V2.1 row
(CD-04, moved here by S-7).

They are not stale copies of anything current — they are the record of a build that
happened, and `contrast-report.json` in particular holds the retired green palette, which
is the reason it must not sit beside the live reports: read out of context it describes
colours this app no longer uses.

Anything the current build produces lives one directory up, in `evidence/`.
